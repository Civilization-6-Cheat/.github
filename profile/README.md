No. This repository is an informational reference and does not contain software that needs to be launched.

### Does Civilization VI have built-in cheat commands?

The PC debug console has limited commands, including map-related options. It does not provide standard commands for adding gold, faith, production, or units.

Yes. Civilization VI supports community-created mods, including gameplay modifications available through the Steam Workshop.

### What is FireTuner?

FireTuner is included in Civilization VI's development tools. It is a debugging and editing utility intended for development and testing workflows.
